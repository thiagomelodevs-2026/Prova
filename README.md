# Motor Financeiro de Corridas

Projeto Java que calcula o pagamento líquido de motoristas de uma plataforma de mobilidade usando classe abstrata, herança e sobrescrita de métodos.

## Executar

Compile os arquivos e execute a classe `Main`:

```bash
javac -d out src/*.java
java -cp out Main
```

O programa imprime o extrato de um motorista iniciante, um premium e um parceiro frotista.
